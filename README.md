# 订单填写助手

企业运作仿真实习物流订单助手，提供正式版和无需学校账号的体验版。两者均为 Windows 10/11 64 位单文件程序，下载 EXE 后双击运行。

## 体验版（无需登录）

[下载体验版](【无需账号】订单填写助手-体验版.exe)

文件：`【无需账号】订单填写助手-体验版.exe`，与正式版放在仓库同一层。

本次交付使用 2026 年 7 月 24 日构建的修正版，复用正式版界面和业务计算模块，替换为独立的本地演示数据。不是另一套重新设计的界面。

- 自动读取 20 条演示订单，可筛选、选择和合并计算运费。
- 支持运输分段调整、合同绑定、回填预览、模拟回填和选车发货。
- 发货后通过“模拟对方付款”推进流程，再生成发票预览并模拟提交。
- 支持订单检查表、物流明细及去重合同导出。
- 预置物流明细和业务规则 PDF，可使用数据分析与知识库检索。
- “恢复演示数据”可重置本地演示业务及对话状态。

体验版不会提交到学校仿真系统。无 API Key 时使用本地规则驱动的对话演示，不代表真实模型推理；需要真实模型时，可在系统设置中自行配置 OpenAI 兼容服务。未内置个人 API Key。

## 正式版（需要学校账号）

[下载正式版](订单填写助手-Win10.exe)

1. 双击 `订单填写助手-Win10.exe`。
2. 输入自己的仿真系统账号和密码并登录。
3. 使用订单获取、运费计算、合同上传、回填、发货、开票、导出和数据分析功能。
4. 需要智能体时，在系统设置中填写自己的模型配置并进行健康检测。
